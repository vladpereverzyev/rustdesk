# Getting help

Before opening an issue, these places answer most questions:

- How to install and use the app: the [README](README.md).
- How the remote desktop works (settings, permissions, connection problems): the
  [RustDesk documentation](https://rustdesk.com/docs/en/), since this app is RustDesk with
  another name.
- Questions and ideas: ask in [Discussions](https://github.com/vladpereverzyev/rustdesk/discussions).

Found a bug in the name, icons, theme, updates or build of this app? Open an
[issue](https://github.com/vladpereverzyev/rustdesk/issues/new/choose) with the version and the
Windows version. A security problem goes to the [security policy](SECURITY.md), not to a public
issue.

Other matters: write to info@vladpereverzyev.com.
